# PCF8563

## Rol en el proyecto
Reloj de tiempo real de la T-Beam Supreme para marcar fecha y hora en el log de vuelo (timestamp) y para alarmas o temporizadores programados. No sustituye la sincronización GNSS. Su pin INT se lleva a GPIO14.

## Interfaz y pines
- SDA 42 / SCL 41 en I2C1 (Wire1). Mismo bus que AXP2101 (0x34).
- INT (interrupción de alarma/temporizador): GPIO14 (`RTC_INT`), open-drain, activa en LOW. Requiere pull-up externo o interno.
- CLKOUT: no conectado a pin de la placa en el mapa LilyGO (no confirmado).

## Configuración relevante para nuestro uso
- Ajustar la hora desde GNSS o desde la estación terrena antes del lanzamiento. Escribir la hora en BCD (registros 02h–08h). Las lecturas bloquean el contador de tiempo durante la transacción I2C (datasheet 8.x, Figura 8); leer todos los registros en una sola transacción para evitar lecturas incoherentes.
- Para el log: leer la hora en la misma transacción de datos que el resto de sensores para tener un timestamp consistente, o usar `esp_timer` para intervalos y el RTC sólo para fecha/hora de referencia.
- Si se usa la alarma o el temporizador: escribir AIE/TIE y limpiar AF/TF tras cada evento. INT permanece activa mientras la bandera siga puesta.
- Detectar pérdida de hora: leer el flag VL tras cada encendido.

## Alimentación y tiempos
- Consumo de backup muy bajo (0.25 µA típico a 3 V, 25 °C).
- Sin cifra de tiempo de arranque del oscilador en lo revisado.
- El RTC mantiene la hora mientras VDD esté por encima de Vlow. Si VDD cae por debajo, VL se activa.

## Trampas y notas
- **Pull-ups**: INT es open-drain; sin pull-up la línea no sube.
- **Escritura de hora**: al escribir la hora, el RTC se detiene brevemente; la hora de escritura debe tomarse con cuidado.
- **Bandera VL**: si VL está activa, la hora no es fiable aunque el RTC siga corriendo.
- **Precisión**: sin calibración, la deriva depende del cuarzo y de la temperatura; no usar como base de tiempo para medir intervalos de vuelo.
- **Compartición de bus**: el AXP2101 y el PCF8563 comparten I2C1. Un bus bloqueado afecta a ambos.
